TakoformTerraform / OpenTofu から Takoform Host を使う

型付きリソースをポータブルな Form contract に対応させる Provider

Provider を使う
Core v1.0.1 を読む

Takoform Provider は、Terraform / OpenTofu の型付きリソースを、互換 Host が 公開する Form contract に対応させます。現在のリリースは Provider 3.0.0、 API/Core v1.0.1 で、forms.takoform.com/v1 を使います。

Install と configure ​

hcl
terraform {
  required_providers {
    takoform = {
      source  = "registry.terraform.io/tako0614/takoform"
      version = "= 3.0.0"
    }
  }
}

provider "takoform" {
  endpoint = "https://forms.example.com"
  space    = "prod"
}

resource "takoform_module_worker" "api" {
  name = "api"
}

endpoint、space、bearer token は TAKOFORM_ENDPOINT、TAKOFORM_SPACE、 TAKOFORM_TOKEN からも設定できます。

Provider の利用には、設定する FormRef を実装した互換 Host が必要です。
