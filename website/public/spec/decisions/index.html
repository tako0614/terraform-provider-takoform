Takoform decisions ​

These records explain normative Takoform product decisions. Current behavior and requirements remain in the owning specification documents; a decision record does not replace them.

  • 0001 — Provider v1 keeps Form versions independent
  • 0002 — Artifact URLs are credential-free persisted state
  • 0003 — SpaceID is an opaque portable scope identity
  • 0004 — Takoform is an experimental specification project
  • 0005 — Current Form Packages use content-addressed publication locators
  • 0006 — v1alpha2 restarts Form lines without reusing v1alpha1 identities
  • 0007 — Current Forms exclude substrate operation
  • 0008 — Forms preserve proven service shape
  • 0009 — Form Families and namespaced API groups
  • 0010 — Exact Interface contracts and typed Bindings
  • 0011 — Resource identity: UID, generation, and revision
  • 0012 — Artifacts use content-addressed upload
  • 0013 — The v1alpha3 lane ships in provider v2.1
  • 0014 — Published schemas are structural minima; closure lives in code and conformance
  • 0015 — Cross-resource references are UID-pinned relations
  • 0016 — The Worker aggregate has one active deployment
  • 0017 — Provider state survives Form evolution and interruption
  • 0018 — The Host API is deployable behind ordinary infrastructure
  • 0019 — The Module Worker ABI is an exact contract, not a date
  • 0020 — The edge Interfaces state their data and delivery model
  • 0021 — Third-party Forms and contract distribution
  • 0022 — A host answers for an exact Form, and a relation pins its target's contract
  • 0023 — The runtime ABI is measured separately from the control plane
  • 0024 — A worker is reachable at an address the host assigns
  • 0025 — A Form's declared outputs are a typed contract, not a JSON blob
  • 0026 — An attachment's claim is decided on canonical, resolved identity
  • 0028 — The resource plane is tenant-isolated, by address
