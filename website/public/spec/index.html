Do not assume novelty

Every new Form starts with OCCI, CIMI, TOSCA, Kubernetes, Crossplane, and provider-native prior art. Takoform does not claim to be an industry standard without independent implementations and adoption.

Read the v1alpha2 epoch decision

Takoform is an Experimental specification project. Current FormRefs use forms.takoform.com/v1alpha2 and current package envelopes use packages.forms.takoform.com/v1alpha3. Provider v2.0.0 is the published current Registry client. Provider v1.0.3 and the 34 published Form Package identities from forms.takoform.com/v1alpha1 are immutable Legacy evidence. There is no current central approval or admission.
