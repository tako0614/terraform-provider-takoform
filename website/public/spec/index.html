Specification ​

Identity ​

An exact FormRef is the join of an API group, a kind, a definition version, and a schema digest. Compatibility is never inferred from a kind name alone: the same kind in a different epoch is a different contract. Form groups are namespaced into Form Families; the Host API group is a protocol compatibility identity independent of any nested Form group.

Current-lane contracts ​

  • Form Families — namespaced Form groups and the Edge Platform Family
  • Host API v1alpha3 — uid/generation/revision identity, long-running operations, fencing
  • Interface contracts — exact capability contracts a Form's service exposes
  • Binding contracts — typed outward capability use held by revisions
  • Artifact transport — content-addressed artifact upload and manifests

Lifecycle ​

A Form moves Proposal → Experimental → Stable → Legacy. Maturity is earned from independent implementation and evidence, never from publication or popularity. Every new Form starts from prior art (OCCI, CIMI, TOSCA, Kubernetes/Crossplane, provider-native resources).

More surfaces ​

  • Proposals — mutable design material for Forms that have not earned a public FormRef
  • Form inventory — generated candidate and family inventory
  • Conformance — executable compatibility evidence
  • Release — provider and Form Package publication boundary
  • Glossary — terms used across the documentation

Takoform is an Experimental specification project. The current design lane is the edge.forms.takoform.com/v1alpha1 family, served over the forms.takoform.com/v1alpha3 Host API with packages.forms.takoform.com/v1alpha4 package envelopes. The forms.takoform.com/v1alpha2 epoch and its packages.forms.takoform.com/v1alpha3 envelope are retained as the provider-v2 compatibility surface. Provider v2.0.0 is the current published client and provider v1.0.3 is the published Legacy client. Provider v2.1.0 is an unpublished source candidate. The 34 published Form Package identities from forms.takoform.com/v1alpha1 are immutable Legacy evidence. There is no current central approval or admission, and no Form has an Experimental publication yet.
