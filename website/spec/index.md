# Takoform Core specification

The current Form, package, and Host API contracts are in the
[Core v1.0.1 specification](https://github.com/tako0614/takoform/tree/v1.0.1/spec).

This Provider site retains old `/spec/` URLs as compatibility links. For
Provider behavior, use the [resource reference](/docs/); for executable checks,
use [Conformance](/conformance/).
