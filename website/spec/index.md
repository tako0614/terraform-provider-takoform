# Specification references

Current provider-neutral API documentation belongs to
[Takoform](https://takoform.com/en/host-api/). Exact Edge Form definitions and
publisher releases belong to
[`takoform-forms`](https://github.com/tako0614/takoform-forms).

This retained projection keeps old `/spec/` URLs as compatibility links. The
[Core v1.0.1 source](https://github.com/tako0614/takoform/tree/v1.0.1/spec)
is the exact v1 checkpoint linked by the published Provider 4 reference.
The local frozen Specification 1.1 bytes and old decisions are release history,
not a new current Specification or Host API publication from this Provider.

Use the [Provider reference](/docs/reference.html) for published v4 mappings
and the [Provider 5 consumer reference](/docs/provider-host-api-v2-source.html)
for the source-v5 contract. Executable Provider checks and their limits are in
[Conformance](/conformance/).
