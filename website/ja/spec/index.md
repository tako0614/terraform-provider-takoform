# 仕様の参照先

現在の provider-neutral な API ドキュメントは
[Takoform](https://takoform.com/host-api/) が所有します。
exact Edge Form の定義と公開は
[`takoform-forms`](https://github.com/tako0614/takoform-forms) が担当します。

この retained projection は、以前の `/spec/` URL を互換リンクとして残しています。
[Core v1.0.1 source](https://github.com/tako0614/takoform/tree/v1.0.1/spec)は、
公開済み Provider 4 reference が参照する exact v1 checkpoint です。
ローカルに固定された Specification 1.1 の bytes と過去の判断記録は release の履歴であり、
この Provider による新しい Specification や Host API の公開ではありません。

公開済み v4 mapping は[Provider reference（英語）](/docs/reference.html)、
ソースの v5 contract は[Provider 5 consumer reference（英語）](/docs/provider-host-api-v2-source.html)を参照してください。
Provider の実行可能な検証とその範囲は[Conformance（英語）](/conformance/)にあります。
